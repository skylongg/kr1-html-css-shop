# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина.

## Текущий статус

Проект подготовлен к сдаче контрольной работы №1.

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки;
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация;
- базовая JS-обработка формы;
- сообщение об успешной отправке;
- текст ошибки под каждым полем формы;
- отзывы покупателей;
- часто задаваемые вопросы.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- Flexbox для шапки и меню (`.site-header__inner`, `.site-nav__list`);
- CSS Grid для сетки карточек товаров (`.products-grid`);
- позиционирование: `relative` у карточки, `absolute` у бейджа, `fixed` и `z-index` у кнопки «Наверх»;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-details` — подробная информация о товаре;
- `product-table` — таблица характеристик;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `order-layout` — структура страницы заявки;
- `order-steps` — шаги оформления заказа;
- `reviews-grid` — сетка отзывов;
- `review-card` — карточка отзыва;
- `faq` — часто задаваемые вопросы;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Самостоятельные доработки

- страница товара `product.html`: изображение, описание, цена, таблица характеристик, похожие товары;
- страница заявки `order.html`: форма и блок с шагами оформления заказа;
- sticky-фильтр каталога: блок фильтров остаётся на экране при прокрутке;
- варианты карточек через БЭМ-модификаторы: `product-card--featured`, `product-card--new`, `product-card--discount`, `product-card--sold-out`;
- категория товара и старая цена в карточках;
- дополнительные состояния кнопок: нажатие (`:active`), отключённая кнопка не реагирует на наведение;
- дополнительные состояния карточек: подъём и тень при наведении, отдельный вид для товара не в наличии;
- фиксированная кнопка «Наверх» на всех страницах;
- отметка текущей страницы в меню через `aria-current="page"`;
- блок отзывов на главной странице;
- блок часто задаваемых вопросов на странице контактов (`details` и `summary`);
- улучшенная доступность формы: обязательные поля отмечены звёздочкой, текст ошибки под каждым полем, связь поля с подсказкой и ошибкой через `aria-describedby`, фокус переходит к первому полю с ошибкой;
- улучшенное модальное окно: кнопка-крестик, название выбранного товара, закрытие по клику на фон, анимация появления, сообщение об отправке внутри окна.
